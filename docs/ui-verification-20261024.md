# LanDrop 1.2.3 界面验证

2026-10-24。本记录对应 1.2.3 的构建和验证，保留既定 Python、pywebview / WebView2 与严格 TypeScript 方案。

## 修改与同类排查

- `landrop/ui_theme.json` 是电脑、手机、标题栏与托盘菜单的颜色来源，前端构建生成 `theme.css`。控件圆角 8px、面板 12px；桌面常规控件 36px，手机表单 48px、图标按钮命中区 44px。
- 首屏阻塞脚本、应用偏好与原生窗口读取同一主题。沿用 `landrop.theme`；桌面偏好同时保存在现有设置中，监听端口变化时仍可恢复，避免原生窗口和 WebView 各自回到系统默认。
- 电脑设置移入独立页面，侧栏为 224px / 56px，窄窗口自动折叠，并保留显式展开入口和手动选择。手机使用页头设置与返回入口。删除重复的页头标题和设置入口。
- 检查发送文件、收到的文件、记录、设置、连接信息、文件夹表单、确认弹窗和传输浮层。统一搜索、选择框、按钮、焦点、错误、滚动条与长文本布局。
- `frontend/ui/focus.ts` 区分指针和键盘输入，不移除真实焦点。弹窗保留错误、字段关联、路径草稿和关闭后的焦点；传输列表支持键盘收起和展开。手机输入或可用高度不足时收起传输浮层。
- 原生标题栏基准 40 个逻辑像素，使用现有品牌 ICO。保留系统移动、缩放、系统菜单及最大化命中机制。按 `GetDpiForWindow` 计算实际 DPI，避免 WinForms `DeviceDpi` 与 WebView2 缩放不同。
- 最小化保留在任务栏；关闭默认进入托盘，可在设置中改为退出应用。首次说明托盘去向，不可用时回退到任务栏。进入托盘不取消传输；明确退出和安装维护沿用正常清理。托盘提供打开和退出，重复启动恢复已有窗口。

前端选择框保留原生 select 的表单与键盘行为，统一页面内触发器及配色；系统展开面板的完整绘制仍由 Windows / 浏览器负责。

## 验证限制

当前会话未提供原生鼠标和键盘控制。标题栏拖动、双击、贴靠、系统菜单、最大化按钮的 Snap 菜单、托盘点击及菜单外观尚未实测。关闭路由与尺寸单元测试不视为这些原生交互已通过。

100%、125%、150% 的真实 Windows DPI、跨显示器移动、Windows 高对比度、实体 Android 扫码、真实软键盘及缺少 WebView2 的机器仍待验证。小高度浏览器模拟不等于真机软键盘测试。构建未签名；发布文件见 [GitHub Release](https://github.com/icelemon233/LanDrop/releases/tag/v1.2.3)。

## 共用规范建议

现有主题、控件、焦点和生命周期条款足够，本次直接应用，没有扩写 skill。建议汇总时补充两个验证样例：

1. WinForms / WebView2 混合窗口同时记录 `DeviceDpi`、`GetDpiForWindow`、原生物理尺寸与 WebView 逻辑尺寸，不能仅根据框架属性判断缩放。
2. 本地 HTTP 桌面宿主更换监听端口时，同时验证首屏 HTML、浏览器偏好与原生主题恢复；长期桌面偏好不应仅依赖某个 HTTP origin 的存储。

原生最大化命中方案参考 [Microsoft Snap Layout 文档](https://learn.microsoft.com/en-us/windows/apps/desktop/modernize/ui/apply-snap-layout-menu)，其实际菜单交互仍在上述待验项目中。
