LanDrop

安装与打开
从 GitHub Releases 下载当前 Windows 安装程序，运行后选择安装位置。重复打开安装包会回到已有的安装或卸载向导。安装完成后，通过桌面或开始菜单中的“LanDrop”打开应用窗口，查看共享文件和二维码。
支持 Windows 10/11 x64。无需安装 Python、Node.js 或手机应用。安装包尚未进行代码签名。
缺少 Microsoft Edge WebView2 时，安装程序会安装该运行时，需要连接互联网。已有运行时时不会重复安装。

电脑发到安卓手机
1. 手机和电脑连接同一个 Wi-Fi；电脑也可以通过网线连接同一台路由器。
2. 在电脑上点击“添加文件”，或“添加文件夹”选择项目的安装包输出目录。
3. 用手机扫码，在系统浏览器中打开链接，点击下载。
4. APK 下载后可在手机文件管理器中打开安装。AAB 不能直接安装；APKS/XAPK 需要手机支持的安装工具。
共享文件夹会定期检查 APK、AAB、APKS、XAPK，包含子目录；刚写入的文件会等待片刻再显示。

手机发到电脑
点击手机页面的“发送文件到电脑”。看到“已保存到电脑”后，在电脑“收到的文件”中查看。
单个上传文件最大 8 GB；同名文件会自动另存，不覆盖原文件。手机下载进度和续传由手机浏览器管理。
拖入电脑窗口的文件会复制到待发送目录；系统文件选择或拖到 exe 图标会直接共享原文件。

连接失败
先确认同一局域网，再检查 VPN、访客 Wi-Fi、路由器设备隔离。多个网卡时切换二维码下方的电脑地址。
Windows 防火墙询问时，允许LanDrop访问你信任的专用网络。微信扫码后可选择“在浏览器打开”。
若手机提示二维码失效，扫描当前电脑窗口中的新二维码。电脑窗口提示登录失效时，重新打开 LanDrop 可恢复本机登录。

退出、升级与卸载
最小化保留在任务栏，关闭窗口默认进入托盘并继续传输。首次会说明去向；托盘不可用时保留在任务栏。双击托盘图标或再次打开 LanDrop 可以恢复原窗口。
设置中可以将“关闭窗口时”改为“退出应用”，外观支持浅色、深色和跟随系统。
选择“退出应用”会停止传输服务；有任务正在传输时会提示确认。
关闭手机网页不会退出电脑程序。
升级或卸载时，安装器会询问是否让正在运行的应用正常退出。先关闭系统文件选择窗口；未完成传输会中断。
共享设置和接收文件保存在 %LOCALAPPDATA%\LanDrop；升级及卸载均保留此目录。
移除共享只影响共享列表，不删除电脑原文件。设置无法读取时程序会保留原件，可手动选择“备份并恢复”。

连接与隐私
文件在局域网 HTTP 连接中传输。适用于信任的家庭或开发网络，不建议使用公共 Wi-Fi。
二维码包含临时连接凭据。点击“重置连接”撤销全部手机访问，或在设备列表中断开指定手机。
“隐藏连接信息”可隐藏二维码、地址、名称和文件夹路径，便于截图。
传输记录只保留本次运行最近 100 条，重启后清空。外观偏好保存在当前设备。
