LanDrop 1.2.0

Windows 桌面窗口
打开程序后使用独立窗口，不再自动启动电脑浏览器。
窗口、任务栏和系统文件选择器使用当前的看板娘图标。
重复打开会回到原窗口，并恢复本机登录；拖到 exe 图标上的文件仍可加入共享。
最小化时继续传输，关闭窗口时正常退出服务。有未完成传输时会提示确认。

安装与升级
安装包会检测 WebView2，缺少时安装 Microsoft 签名的运行时。
升级保留收到的文件和共享设置；安装、升级和卸载仍请求正常退出，不强制结束旧版。
手机端继续通过扫码和浏览器连接，无需额外安装手机应用。

验证
77 项后端测试、8 项前端测试、类型检查与生产构建通过。
真实 exe 的独立窗口、本机登录、重复打开、退出重开、双向传输、旧版升级及隔离安装卸载通过。
已检查真实窗口的标题栏、图标、系统文件选择和关闭按钮。
实体安卓和 Windows 10 尚未实测，安装包尚未签名。

1.1.2 图标与工程归属记录

工程归属
工程名 LanDrop，属于 Cinna 系列应用，开发者署名统一为 Cinna，归属记录在 project.json。
界面使用“LanDrop”名称。

图标
沿用最新 Cinna 系列看板娘的画风与人物，加入手机和文件双向箭头道具。
exe、安装器、卸载器、桌面与开始菜单快捷方式、系统应用入口、浏览器页签、界面品牌图和 README 共用这一版本的图标。
安装向导侧栏和页头也使用同一素材。系统窗口共用图标入口。
保留生成原图、高清母版、ICO、网页图标和 README 圆角 PNG，并提供导出哈希清单。

验证
64 项后端测试与 8 项前端测试通过；真实 exe 的启动、双向传输、升级和安装卸载通过。
已核对安装器、应用及卸载器的图标资源、开发者字段和快捷方式图标路径。
修复退出清理期间读取临时运行文件可能造成的误报，升级仍通过正常退出流程完成。

安装包尚未签名。实体安卓扫码尚未实测。用户文件和共享设置沿用原目录。
