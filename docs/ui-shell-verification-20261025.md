# LanDrop 窗口与控件统一 QA

此记录对应 2026-10-25 的本地 QA 构建，产品版本仍为 1.2.4。没有发布 GitHub Release、替换正式安装目录或重建安装器。工作区原有 Inno 迁移保留；此次便携 QA 构建使用独立输出和工作目录。

## 实现

- `landrop/window_shell.json` 是项目内的尺寸契约，原生标题栏直接读取，前端构建生成 CSS 变量。`landrop/ui_theme.json` 共用深浅配色。运行时不读取用户的 skill 目录。
- 原生标题栏为 44 DIP，业务图标 24、左距 16、名称间隔 8；14px Regular 名称；三个按钮 46×44，图形 10、线宽 1。普通与最大化圆角交给 DWM。
- 最大化按钮及其父面板在该区域让出命中，顶层窗口返回 HTMAXBUTTON，保留 Windows 的非客户区悬停与按下／释放处理。最小化和关闭继续由 WinForms 按钮处理，系统菜单、标题栏拖动和双击保留。
- 四条原生缩放命中条位于 WebView2 子 HWND 之上，统一覆盖四边四角；将非客户区按下交给顶层窗口的 Windows 缩放循环。它们不改变 Web 内容布局，也不通过前端设置尺寸模拟拖动。
- 侧栏固定占 224，取消固定占 56；悬停展开 224 浮层，约 150ms 移出收起。键盘可见焦点、菜单和拖动保持浮层。只保存固定偏好，兼容原 `sidebar-collapsed` 选择。设置／图钉位于底部同一行，宽 164／36、间距 8、行高 40；收起不留图钉 Tab 入口。窄屏使用抽屉与背景 inert。
- 页面标题位于 48px 工具栏，设置正文距边 24；分组线随内容区全宽，字段宽 320。保留电脑名称、传输和关闭方式等业务内容。
- 普通操作图标由固定版本 Lucide 静态包生成所需 SVG sprite，18px、线宽 1.65；人物业务图标和品牌导出未更换。
- 主题、关闭方式及地址选择共用增强 select；保留原生 select 的值、标签和表单语义。弹层共用主题、36px 行、4px 内距、12px 圆角，支持方向键、Home/End、Enter/Space、Esc、Tab、外部点击和焦点返回。选项结构变化会关闭旧菜单，提交时校验选项快照，避免地址列表更新造成索引错选。
- `--qa-loopback` 只允许与独立 `--test-data` 配合，不改变正常局域网服务。QA 的 AppUserModelID、托盘说明、数据和 WebView 配置独立。

## 已执行

- `pnpm check`、`pnpm build`、`pnpm test`：通过，前端 15 项。
- `python -m unittest discover -s tests -v`：86 项通过。
- IAB 浏览器：深浅主题、主题菜单、Esc 与外部点击、异步保存焦点恢复、固定／取消固定、悬停内容不移位、键盘保留浮层、偏好重新加载、800×556 内容视口、560px 抽屉与 Esc，13 项交互检查通过。另以合成地址验证菜单打开后选项变化：旧菜单关闭、零误提交，重开后选择正确值。
- 最终原生 EXE：隐藏且不激活的真实 WebView2 宿主加载、设置页、托盘可用、原生／DOM 实际布局、八处缩放及三个标题栏区域的自身 HWND 命中路由。该验证没有使用物理桌面指针。
- Windows 实测 HWND DPI 192；WebView DPR 2、ZoomFactor 1、visualViewport scale 1。WinForms DeviceDpi 返回 96，不能据此把实际窗口称为 100%。

## 实测布局

原生矩形为物理像素；DOM 为 WebView 内 CSS 像素。完整屏幕坐标含 DWM 可见边缘、GetWindowRect、客户区原点及 WebView 原点，见隔离记录 `evidence/packaged-window.json` 的 `native.frameGeometry`。

| 区域 | 实测 | 对应逻辑值 |
| --- | --- | --- |
| 原生窗口 | 2360×1560 | 1180×780 DIP |
| 标题栏 | 2360×88 | 高 44 DIP |
| 图标 | x32、y20、48×48 | 左距 16、24×24 DIP |
| 名称 | x96、10.5pt、Regular | 起点 48、14px／400 |
| 标题栏按钮 | 各 92×88 | 46×44 DIP |
| 工具栏 | x224、y1、956×48 CSS px | 高 48 |
| 设置正文 | x248、y73、宽896 CSS px | 距内容区左／上 24 |
| 导航首行 | x8、y5、208×40 CSS px | 40 行；顶部内距 4 |
| 导航图标 | x19、y16、18×18 CSS px | 中心 x28 |
| 底部设置 | x8、y688、164×40 CSS px | 内距 8 |
| 底部图钉 | x180、y690、36×36 CSS px | 居中，间距 8 |
| 主题选择 | 320×36 CSS px | 圆角 8 |

本次隐藏正常窗口的 `GetWindowRect` 与 `DWMWA_EXTENDED_FRAME_BOUNDS` 均为物理矩形 `(441,441)-(2801,2001)`，客户区原点 `(441,441)`，WebView 原点 `(441,529)`；宿主四侧 padding 均为 0。它们在本次实测中没有额外的可见边框偏移。

## 运行与待验收

QA 根目录：`<project-root>/.local/ui-shell-20261025`。运行其中 `start-qa.ps1`；窗口识别名和托盘说明为 `LanDrop · UI QA`。首次为正常窗口、1180×780 DIP、深色、设置页、侧栏固定。`stop-qa.ps1` 请求正常退出并等待收尾，不强杀进程。重开使用同一目录和端口保留侧栏偏好。

本次不占用前台桌面。物理鼠标拖动四边四角、原生拖动／双击／贴靠、Windows 11 最大化悬停菜单、普通圆角与最大化直角、系统菜单、最小化／还原／托盘／退出以及跨应用并排比较，由父任务在用户处理安全提示后统一验收。100%、125%、150% 系统 DPI 未实测；缩放参数单元测试与浏览器视口变化不替代这些验收。

微软对自定义最大化按钮的要求参见 [Snap Layouts 支持说明](https://learn.microsoft.com/en-us/windows/apps/desktop/modernize/ui/apply-snap-layout-menu)。本记录中的命中检查不代表悬停弹层已经经过物理鼠标验证。
